Вообщем, Проект создан для показа каталога книг

1. в терминал pip install -r requirements.txt
2. в терминал что б запустить проект uvicorn main:app --reload
3. После запуска API будет доступно по адресу: `http://127.0.0.1:8000`
   4. энд поинты: - *GET `/`* — Информация об API.
                 - *GET `/books`* — Список всех книг в формате JSON.
                 - *GET `/docs`* — Интерактивная документация Swagger (здесь можно протестировать запросы).
